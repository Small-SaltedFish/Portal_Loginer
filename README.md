# Portal Loginer

在 OpenWrt / KWrt 上自动登录校园网。填写账号和密码后，插件会定时检查网络，在校园认证失效时尝试重新登录。

插件适用于本项目使用的校园认证系统，并不支持所有学校。更换学校前，需要先确认认证方式是否兼容。

## 安装

1. 从 [Releases](https://github.com/Small-SaltedFish/Portal_Loginer/releases) 下载 `.ipk` 安装包。
2. 打开路由器后台的 **系统 → 软件包**，上传并安装。
3. 进入 **服务 → Portal 自动登录**，填写校园网账号和密码。
4. 打开启用开关，保存配置，再点“启动”。

密码留空保存时，会保留原来的密码。其余设置通常保持默认即可。

## 升级

升级前先备份路由器配置。下载新版本安装包后，通过软件包页面安装。

从旧版 1.3 升级时，推荐同时下载 `install-upgrade.sh`：旧版安装包可能在升级时覆盖配置或关闭自启动，助手会先备份并恢复这些设置。

```sh
sh install-upgrade.sh ./luci-app-portal-login_版本号_all.ipk
```

助手只在升级时运行，平时不需要启动。下载文件的 SHA256 可在 GitHub 的附件信息中查看，不另提供重复校验文件。

## 日常使用

- **启动**：开始自动检查和登录。
- **停止**：暂停自动检查，保留当前校园登录。
- **重启**：重新读取配置，不主动注销校园账号。
- **立即登录**：手动重新认证，可能短暂影响网络；已经在线时一般不需要点击。

正常时，页面显示“网络在线”。遇到“等待 WAN”时，先等光猫启动并分配地址；遇到“探测未确认”时，查看下面的日志，不要连续点击登录。

## 常用设置

| 设置 | 怎么选 |
|---|---|
| 主探针 URL | 通常保留默认。它是用于检查网络的地址，不是校园登录页 |
| 在线检测间隔 | 默认 30 秒；调短会增加请求次数 |
| 失败重试间隔 | 第一次失败后等待多久；连续失败时插件会逐步延长等待 |
| 每日重新登录时间 | 填 0–23；不需要定时重登录时填 -1 |
| 调试日志 | 排查问题时再打开 |

插件有三个检测地址：先检查设置页中的主探针，没得到明确结果时，再依次检查华为和 vivo 的备用地址。正常时不会每次请求三个。

## 同时使用代理插件

代理节点故障与校园认证失效是两回事。Portal Loginer 不应因为一次超时就反复注销、登录。

从 **1.4.1** 起，插件会自动识别 OpenClash 已有的本机绕过机制，让检测和认证请求直接访问校园网络。通常无需添加规则、登记探针域名或关闭路由器本机代理，也不会修改你的 OpenClash 配置。

未安装或未运行 OpenClash 时，直接使用正常网络。遇到不支持的防火墙配置时，插件会显示原因，保留当前校园登录，避免盲目反复认证。

详见 [代理环境使用说明](docs/OPENCLASH.md)。
